Dove trovare la tua chiave API

Ogni fornitore ha un suo pannello. Crea lì la chiave, copiala subito (viene mostrata una volta sola) e incollala nel campo qui accanto.

Anthropic (Claude)

La chiave inizia con sk-ant-
  1. Vai su console.anthropic.com e accedi (o crea un account).
  2. Apri Settings → API keys.
  3. Clicca Create Key, dai un nome e copia subito la chiave.
Serve un metodo di pagamento in Billing perché la chiave funzioni.

OpenAI (GPT)

La chiave inizia con sk-
  1. Vai su platform.openai.com e accedi.
  2. Apri Settings → API keys.
  3. Clicca Create new secret key, dai un nome e copia subito la chiave.
Serve un metodo di pagamento in Billing perché la chiave funzioni.

Google (Gemini)

Chiave di Google AI Studio
  1. Vai su aistudio.google.com e accedi con il tuo account Google.
  2. Clicca Get API key (Ottieni chiave API) nel menu a sinistra.
  3. Clicca Create API key e copia subito la chiave.
Gratis, senza carta di credito: ideale per iniziare.
